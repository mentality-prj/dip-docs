# QDIP Grant Target Register

Last checked: **2026-10-03**

## Financing gate

A program is an active QDIP target only if all mandatory conditions pass:

1. it provides real non-repayable project/R&D/startup financing rather than a hackathon, bootcamp, pitch prize, award, or competition whose payment is merely a prize;
2. a single-applicant / mono-beneficiary path exists;
3. no mandatory consortium is required;
4. no mandatory applicant cash co-financing is required;
5. there is no loan, repayable advance, revenue repayment, grant-equivalent repayment, mandatory tax/social-contribution return, or other economic-return obligation tied to the funding;
6. no mandatory equity transfer is required;
7. QDIP fits the technical objective without inventing a grant-specific agriculture/green/defence/LLM use case or changing the Universal Runtime thesis;
8. an eligible applicant entity can exist in time for submission;
9. timeline and payment structure are executable;
10. IP/security/open-science obligations are acceptable and do not require open-sourcing QDIP Core, Canonical Decision IR, or runtime.

## Application architecture

```text
Canonical Evidence Pack
        ↓
program eligibility + financing/IP gate
        ↓
program-specific overlay
        ↓
work packages + budget + forms
        ↓
submission package
```

Do not fork the thesis, benchmark evidence, Canonical Decision IR, core IP position, or experiment manifests merely to fit a grant.
