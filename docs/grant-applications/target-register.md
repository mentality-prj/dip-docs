## Decision rule for adding a target

A new program enters the active register only after verifying:

1. official call is open or has a credible announced next window;
2. eligible applicant entity exists/can be ready in time;
3. single-applicant path exists;
4. no mandatory own co-financing;
5. QDIP fits the technical objective without changing Core thesis;
6. timeline and payment structure are executable;
7. IP/open-source/security obligations are acceptable.
