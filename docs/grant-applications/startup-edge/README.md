## 1. Why this folder exists

Startup EDGE is an application target, not a separate research project. This folder maps the canonical QDIP Universal Runtime evidence to the Startup EDGE application/evaluation format.

Do not fork the QDIP thesis or Test A/B/C methodology here.

## 2. Current official program profile

Official USF program page currently states:

- target: early-stage Ukrainian startups;
- focus sectors: Deep Tech, Green Tech, EdTech;
- Deep Tech explicitly includes artificial intelligence and machine learning;
- pre-seed support: up to EUR 20,000;
- seed support: up to EUR 40,000;
- application process: compliance → expert evaluation → pitching/Selection Committee → Supervisory Board approval → grant agreement;
- next open call: officially announced as coming soon / notification registration available.

Official source:

- https://usf.com.ua/en/programs/startup-edge
- https://usf.com.ua/programs/startup-edge

The first 2026 cohort received more than 190 applications and awarded grants to nine startups. Treat first-cohort rules as historical unless the next call explicitly reuses them.

## 3. QDIP fit

Primary category: **Deep Tech — AI/ML / decision intelligence / mathematical optimization infrastructure**.

Application positioning should be:

> QDIP is a lightweight Universal Decision Runtime that converts structured operational decision problems into uncertainty-aware, economically evaluable and auditable actions. The technical R&D thesis is that a frozen reusable decision semantics/runtime can preserve non-inferior decision quality relative to specialized implementations while reducing domain-marginal engineering effort by at least 50%.

Do not position QDIP as:

- a generic chatbot;
- another dashboard/BI tool;
- a new mathematical solver;
- an unvalidated claim of universal AI superiority.

Unlike BattleVerse, Startup EDGE does not require a defence- or LLM-specific product reframing. This is therefore the primary generic application target.

## 7. Recommended Startup EDGE scope

Startup EDGE funding is too small for the full A+B+C research program. Use it for a bounded milestone that materially advances the Universal Runtime thesis.

### Pre-seed EUR 20k candidate scope

- finalize Canonical Decision IR v1;
- freeze Core/IR/API;
- complete Test A implementation and reproducible benchmark pipeline;
- produce first quantitative evidence;
- prepare external validation/pilot.

### Seed EUR 40k candidate scope

- all above;
- complete Test B Procurement;
- prepare/execute blind Test C where feasible;
- production hardening and external validation;
- commercialization/pilot preparation.

Exact scope must be aligned with the next-call eligible-cost rules before submission.

## 9. Submission gate

Startup EDGE application is ready only when:

- next-call rules are archived/versioned;
- all eligibility items are PASS;
- requested stage and amount are justified;
- application claims map to canonical evidence;
- no unverified Test A/B/C result is written as established fact;
- budget maps directly to grant milestones;
- pitch narrative is consistent with the written application;
- final application answers are reconciled with the current Canonical Evidence Pack.
