# F. Innovation Analysis — Comparative Table

> R&D Grant Package
> Version: 0.1 | 2026-08-08 | Draft

## Purpose

Довести **щонайменше національний рівень інноваційності** через систематичне порівняння запропонованого підходу з відомими методами.

> Важливо: не стверджувати «ми перші у світі» до проведення систематичного огляду літератури та патентного пошуку. Ця таблиця є **попередньою** і потребує верифікації через literature review у межах Д1.

## 1. Огляд класів методів

### Метод → Що вміє → Чого не вміє → Наш внесок

| Метод                                                     | Що вміє                                          | Чого не вміє                                                                                    | Наш внесок                                                                          |
| --------------------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Фіксовані порогові правила** (stress ≥ 4.0 → high risk) | Простий, прозорий, без навчальних даних          | Не персоналізований; не враховує динаміку; немає невизначеності; фіксовані пороги               | Персоналізований baseline (EWMA); динамічний вектор стану; формальна невизначеність |
| **Популяційний z-score** ((s − μ) / σ ≥ 1.5)              | Враховує популяційний розподіл                   | Поділяє baseline для всіх; немає часового виміру; немає оцінки невизначеності                   | Індивідуальний EWMA-baseline; багатовимірний вектор замість одного показника        |
| **Логістична регресія** (trained)                         | Статистично обґрунтована; хороший AUROC          | Лінійна; не враховує динаміку стану; point estimate; вимагає labeled data                       | Явна модель динаміки стану; мінімаксні межі без потреби великих labeled вибірок     |
| **LSTM / RNN**                                            | Моделює довгострокові залежності                 | Black-box; нестабільний при drift; немає інтерпретованої невизначеності; потребує великих даних | Інтерпретованість; стабільність при drift; формальні межі невизначеності            |
| **HMM (Hidden Markov Model)**                             | Моделює латентні стани; ймовірнісний             | Потребує великих вибірок; складна інтерпретація; не дає мінімаксних bound                       | Явне представлення state vector; feasible state space; менша вимога до даних        |
| **Конформне прогнозування**                               | Дає статистично гарантовані prediction intervals | Не враховує структуру стану; не моделює динаміку; рідко застосовується у wellbeing              | Доменно-специфічний state vector + мінімаксні bound у wellbeing контексті           |
| **Bayesian networks**                                     | Оцінка ймовірності з апріорним знанням           | Потребує expertly defined structure; складне калібрування; статичний snapshot                   | Навчається з даних (EWMA оптимізація); динамічне оновлення без ручного графа        |
| **Wellbeing HR-платформи** (Gallup Q12, etc.)             | Просто збирають та відображають                  | Без предиктивних моделей; без динаміки; без невизначеності                                      | Prediktyvna модель + explainability + decision support                              |

## 3. Оцінка рівня інноваційності

### 3.1 Аргумент для «національного рівня»

Комбінація таких властивостей в одній системі для домену mental wellbeing:

1. Персоналізований EWMA-baseline з bootstrap довірчими інтервалами
2. Мінімаксне оцінювання в межах feasible state space
3. Явна оцінка системної стабільності
4. Формалізоване поширення ризику на командний рівень

…не задокументована в доступній літературі для корпоративного wellbeing домену _(потребує верифікації через systematic literature review у Д1)_.

### 3.2 Що потребує верифікації перед стверджуванням новизни

- Систематичний огляд: IEEE, ACM, PubMed, arXiv за ключами:
  `"behavioral risk" + "state space"`, `"wellbeing prediction" + "uncertainty"`, `"mental health" + "minimax"`, `"EWMA" + "risk" + "personalized"`
- Патентний пошук: USPTO, EPO, UPRP
- Порівняння з комерційними продуктами: Spring Health, Lyra Health, Modern Health (технічні описи, whitepapers)

## 5. Висновок (попередній)

Запропонований метод комбінує компоненти, які окремо описані в літературі, але **у поєднанні для wellbeing домену з формальними гарантіями** — ймовірно є новим підходом на національному рівні.

Остаточне підтвердження новизни — після systematic literature review у межах Д1 проєкту.
