# G. Бюджетна структура

> R&D Grant Package
> Version: 0.1 | 2026-08-08 | Draft

## Принцип

**Ядро заявки — B+R.** Бюджет будується навколо дослідницької роботи, а не розвитку SaaS. Конкретні суми заповнюються за регламентом цільового конкурсу; нижче — структура і принципи допустимості.

---

## 1. Категорії витрат та обґрунтування

| Категорія                        | Що входить                                                                           | B+R-обґрунтування                                                              | Приблизна частка |
| -------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ | ---------------- |
| **Персонал — дослідники**        | ML Engineer (дослідницька роль), Data Scientist, Algorithm Developer                 | Безпосередньо реалізують Д1–Д10: формалізація, оптимізація, алгоритм, прототип | 35–45%           |
| **Персонал — наукові партнери**  | КНУ: викладачі + аспіранти (через субконтракт або співпрацю)                         | Теоретична верифікація, статистична методологія, публікації                    | 15–20%           |
| **Обчислювальна інфраструктура** | Cloud compute (GPU для навчання), storage для datasets і артефактів, CI/CD pipelines | Необхідна для Д6–Д10: навчання, backtesting, відтворюваність                   | 10–15%           |
| **Дані та ліцензії**             | Синтетичні датасети (CTGAN), тестові середовища, ліцензії на спеціалізоване ПЗ       | Д10: валідація на даних; синтетика як альтернатива реальним                    | 5–10%            |
| **Дисемінація та захист**        | Конференції (IEEE, ACM, NeurIPS), публікаційні збори, патентний пошук                | Очікувані наукові публікації (Д7–Д8)                                           | 5–8%             |
| **Управління проєктом**          | PM, юридичний супровід (угода з КНУ, DMP, etyka)                                     | Координація B+R, compliance, звітність                                         | 5–8%             |
| **Непрямі витрати**              | Overhead за ставкою установи                                                         | Відповідно до правил конкурсу                                                  | 15–25%           |

## 2. Що НЕ включати (типові помилки)

| Стаття                                      | Чому не включати                          |
| ------------------------------------------- | ----------------------------------------- |
| Маркетинг і продажі                         | Не пов'язано з B+R; окрема лінія (якщо є) |
| Розробка production SaaS features           | B+R — це дослідження, не продукт          |
| Загальноадміністративні витрати понад ліміт | Обмежені правилами конкурсу               |
| Витрати до початку проєкту                  | Недопустимі за будь-яким регламентом      |

---

## 3. Підхід до розрахунку для Ścieżka SMART (2026 reference)

- **Maks. dotation**: до 80% допустимих витрат (для МСП без підрядника)
- **Maks. wartość projektu**: без обмеження (але B+R має бути обґрунтованою)
- **Subkontrakt z KNU**: допустимий як субпідряд; потребує обґрунтування необхідності й конкурентного вибору
- **Zasada kwalifikowalności**: кожна стаття має бути прив'язана до завдань B+R у формі заявки

## 4. Зв'язок бюджету з B+R-завданнями

| Завдання           | Основні статті витрат                           |
| ------------------ | ----------------------------------------------- |
| Д1 Формалізація    | Персонал (KNU + ML Engineer), literature access |
| Д2–Д3 Моделі       | Персонал (ML Engineer + KNU)                    |
| Д4–Д5 Оптимізація  | Персонал + compute (GPU)                        |
| Д6 Алгоритм        | Персонал (Algorithm Developer)                  |
| Д7–Д8 Експерименти | Compute + персонал + datasets                   |
| Д9 Прототип        | Персонал + інфраструктура                       |
| Д10 Валідація      | Compute + datasets + персонал                   |
| Дисемінація        | Конференції + публікаційні збори                |
