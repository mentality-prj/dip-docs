# R&D Grant Package — Науковий дослідницький проєкт

> Призначення: універсальний пакет для подання в різні грантові програми (PARP Ścieżka SMART, Horizon Europe EIC, Eurostars та інші)
> Статус: Підготовка
> Поточний цільовий конкурс: вказати при адаптації

## Три речі, які має довести цей пакет

1. **Є наукова проблема** — існуючі методи оцінювання поведінкового ризику на рівні фізичних осіб мають конкретні, вимірювані обмеження.
2. **Є конкретна гіпотеза** — векторно-часовий підхід із мінімаксним оцінюванням є кращим за базові методи за визначеними метриками.
3. **Є спосіб довести або спростувати** — задано baseline, дані, метрики, протокол розподілу і статистичні тести.
