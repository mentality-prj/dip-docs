# Verification Plan

Language: [Українська (default)](verification-plan.md) | English

## Purpose

Describe how SRS requirements will be verified through tests, benchmarks, audits, and user validation.

## Verification Types

- API/contract tests
- Integration tests
- Performance benchmarks
- Security checks
- Reproducibility replay
- User validation studies

## Execution Rules

- Verification evidence must be versioned.
- A requirement is considered `Done` only when its verification status is `Done` in the matrix.
- Partial evidence must be marked `Partial` and reviewed in the next cycle.
