# Verification Plan

## Purpose

Описати, як вимоги SRS будуть верифіковані через тести, benchmark-и, audit-и та user validation.

## Verification Types

- API/contract tests
- Integration tests
- Performance benchmarks
- Security checks
- Reproducibility replay
- User validation studies

## Execution Rules

- Verification evidence must be versioned.
- A requirement is considered "done" only when verification status is `Done` in the matrix.
- Partial evidence must be marked `Partial` and reviewed in the next cycle.
